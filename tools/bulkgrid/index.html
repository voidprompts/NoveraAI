Overview

What Bulkgrid does

Bulkgrid indexes selected websites and public or private GitHub repositories so AI agents can retrieve current passages with verifiable references. It handles crawling, content processing, change detection, scheduled refreshes, and search access through MCP, a REST API, SDKs, or a CLI. The free plan searches existing public sources with monthly limits; Pro adds source creation, private sources, larger allowances, and configurable refresh schedules.

Decision context

Best fit

Bulkgrid is most relevant to people who want to index websites and public or private GitHub repositories for agent retrieval. It is positioned in Research & Knowledge; the official product should be checked against the exact workflow, data, and output requirements before adoption.

Capabilities

Key features

  • Index websites and public or private GitHub repositories for agent retrieval
  • Track additions, updates, and removals through scheduled source refreshes
  • Retrieve relevant passages with references through MCP or a REST API
  • Connect with TypeScript and Python SDKs or manage sources from a CLI
  • Use existing public sources on the free plan or create private sources on Pro
Evaluation checklist

Before you choose

  • Check the current free-tier allowance, feature restrictions, watermark or export limits, and the cost of the expected paid usage.
  • Inspect source coverage, citation quality, freshness, and the ability to open original evidence.
  • Verify important claims independently; confident language does not guarantee accuracy.
  • Review upload privacy, retention, team access, and export controls.
