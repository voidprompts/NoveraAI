Overview

What aclif does

aclif is an MIT-licensed command-line framework built for AI agents that need to work across SaaS APIs. Instead of loading a fixed catalog of tool definitions into every model turn, an agent discovers a provider and requests a command’s schema, examples, shape, cost estimate, and safety metadata only when needed. Commands share one JSON envelope and error vocabulary, support dry runs and confirmation rules, and can run from an agent process, an embedding host, or a credential-holding gateway. The reference TypeScript CLI is free on npm and currently includes providers such as Salesforce and ServiceNow.

Decision context

Best fit

aclif is most relevant to people who want to expose multiple SaaS providers through one command grammar and JSON response envelope. It is positioned in Coding & Development; the official product should be checked against the exact workflow, data, and output requirements before adoption.

Capabilities

Key features

  • Expose multiple SaaS providers through one command grammar and JSON response envelope
  • Load command schemas and examples on demand instead of keeping every tool in model context
  • Resolve canonical names against tenant-specific objects and fields
  • Declare mutability, blast radius, reversibility, idempotency, and confirmation requirements
  • Run as an agent-spawned CLI, an embedded runtime, or a gateway that keeps credentials away from agents
