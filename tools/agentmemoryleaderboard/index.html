What Agent Memory Leaderboard does

Agent Memory Leaderboard is a public evaluation platform for textual, multimodal, and coding-agent memory systems. Participants expose fixed Add and Search endpoints, pass a smoke test, and submit formal jobs that use the platform’s standardized answer, scoring, review, and publication flow. Public boards separate open-source methods from commercial products and break results down across recall, inference, temporal reasoning, governance, personalization, context execution, safety, and privacy. Participation is free, although entrants pay for their own APIs, databases, bandwidth, and compute.

Key features

  • Evaluate memory systems through a fixed Add and Search API contract
  • Use separate tracks for textual, multimodal, and coding-agent memory
  • Run private smoke tests before submitting a complete formal evaluation
  • Compare systems with standardized capability-level and overall scores
  • Publish approved results on separate open-source and commercial leaderboards
