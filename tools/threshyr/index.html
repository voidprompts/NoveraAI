What Threshyr does

Threshyr is a local-first time tracker for Windows and macOS that records active applications, supported browser domains, duration, and idle periods without manual timers. Rules and an on-device model classify activity by project, while focus views and reports summarize productive time and billable work. The pre-release is free without an account or card; the developer lists a future $58 yearly license, with a discounted first year. Firefox and Linux are not currently supported.

Key features

  • Record application and supported-browser activity without starting a timer
  • Classify activity into projects with local rules and an on-device model
  • Review or correct classifications and create reusable tagging rules
  • Summarize focus, distractions, productive time, and client billing totals
  • Run locally on Windows or macOS without an account during the free pre-release
