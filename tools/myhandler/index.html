MyHandler

Search and draft from locally stored screen, file, meeting, and messaging context on Windows.

Official website
Overview

What MyHandler does

MyHandler is a Windows AI assistant that builds an encrypted, on-device memory from selected screen text, files, meetings, calendars, and connected communication channels. It can answer recall questions, draft replies without sending them, and provide local voice dictation. A local model is available by default, while optional cloud processing uses plan credits; a free tier and paid plans are offered.

Decision context

Best fit

MyHandler is most relevant to people who want to search selected screen activity, files, meetings, and messages. It is positioned in Productivity & Automation; the official product should be checked against the exact workflow, data, and output requirements before adoption.

Capabilities

Key features

  • Search selected screen activity, files, meetings, and messages
  • Draft context-aware replies without automatically sending them
  • Dictate into Windows applications with on-device transcription
  • Keep an encrypted local archive and optionally disable cloud AI
Evaluation checklist

Before you choose

  • Check the current free-tier allowance, feature restrictions, watermark or export limits, and the cost of the expected paid usage.
  • Confirm required integrations, permissions, usage limits, and supported data sources.
  • Test failure handling, approval controls, logs, and recovery before automating important work.
  • Review how workspace data is stored, shared, and removed.
