What Biom does

Biom is a visual workspace for material produced by AI agents. An agent writes into a local folder, and Biom presents the results as pages, documents, dashboards, diagrams, tables, boards, forms, or automations that people can inspect and continue editing. The local AGPL-licensed application works with agents that can write files and is free to build and run. Paid collaboration, hosted-agent, sync, web, and mobile plans are listed but were not yet generally available at review time.

Key features

  • Turn agent-written files into visual documents, dashboards, diagrams, and forms
  • Work with Claude Code, Codex, OpenClaw, and other agents that can write files
  • Keep pages, data, boards, roadmaps, and automations together in one folder
  • Build and run the AGPL-licensed local application on macOS or Windows
  • Use the free local workspace while hosted collaboration plans remain on a waitlist
