1. S-Roll

Find, reframe, caption, and export strong clips from long videos entirely on your Mac.

S-Roll is a local AI clipping editor for long-form video on Apple silicon Macs. It transcribes and analyzes footage on-device, scores promising moments, and lets users describe a moment in chat to locate and cut it. Automatic subject tracking reframes clips for vertical video, while the editor supports trimming, captions, titles, and reusable brand presets before MP4 export. Videos, transcripts, chats, project names, and exports stay on the Mac; sign-in, updates, and the initial model download use the internet. The app is currently free with no watermark.

  • Score long videos and review candidate clips with titles, summaries, and previews
  • Find a specific action, moment, or topic by chatting with the video
  • Track a subject automatically while reframing footage for vertical clips

2. Facefork

Explore branching AI photo edits on a visual canvas using your own OpenRouter key.

facefork is a browser-based canvas for branching AI photo edits. Each prompt creates a child node under the selected image, making it possible to compare alternatives, continue from any result, or combine two photos. Trees are saved in the browser and can be exported as a project file or turned into shareable before-and-after images, magazine covers, polaroids, and short loops. The static open-source app is free and requires the user’s own OpenRouter key; model-provider usage charges apply. Photos remain in the browser until an edit sends the selected prompt and references directly to OpenRouter.

  • Create a new branch for every prompted photo edit
  • Continue from any result or combine two selected photos in one edit
  • Compare a node with its parent and star preferred results

3. Agent Memory Leaderboard

Compare agent-memory systems through a consistent public Add/Search evaluation framework.

Agent Memory Leaderboard is a public evaluation platform for textual, multimodal, and coding-agent memory systems. Participants expose fixed Add and Search endpoints, pass a smoke test, and submit formal jobs that use the platform’s standardized answer, scoring, review, and publication flow. Public boards separate open-source methods from commercial products and break results down across recall, inference, temporal reasoning, governance, personalization, context execution, safety, and privacy. Participation is free, although entrants pay for their own APIs, databases, bandwidth, and compute.

  • Evaluate memory systems through a fixed Add and Search API contract
  • Use separate tracks for textual, multimodal, and coding-agent memory
  • Run private smoke tests before submitting a complete formal evaluation
Read the Agent Memory Leaderboard listing

4. aclif

Give AI agents one inspectable command grammar across multiple SaaS providers.

aclif is an MIT-licensed command-line framework built for AI agents that need to work across SaaS APIs. Instead of loading a fixed catalog of tool definitions into every model turn, an agent discovers a provider and requests a command’s schema, examples, shape, cost estimate, and safety metadata only when needed. Commands share one JSON envelope and error vocabulary, support dry runs and confirmation rules, and can run from an agent process, an embedding host, or a credential-holding gateway. The reference TypeScript CLI is free on npm and currently includes providers such as Salesforce and ServiceNow.

  • Expose multiple SaaS providers through one command grammar and JSON response envelope
  • Load command schemas and examples on demand instead of keeping every tool in model context
  • Resolve canonical names against tenant-specific objects and fields
Read the aclif listing

5. TabMail

Add AI summaries, drafting, triage, search, and approved actions to existing email accounts.

TabMail is an AI email client available as a Thunderbird extension and an iPhone app for Gmail, Outlook, iCloud, and generic IMAP accounts. It summarizes messages, prepares replies, rewrites drafts from conversational instructions, tags mail for triage, searches the inbox, works with calendar data, and can propose actions that require confirmation. Search and personalization data stay on the device; email or calendar content may be sent temporarily for AI processing under the service’s zero-data-retention policy. The MPL-2.0 clients are open source, while the hosted AI backend is proprietary. The iOS app is free to download with a trial and paid in-app plans.

  • Summarize messages and extract key points, action items, and deadlines
  • Prepare replies, autocomplete drafts, and apply conversational edits
  • Chat with email and calendar data, then confirm proposed actions before execution
Read the TabMail listing

6. Slaunt

Give workplace agents shared context, governance controls, and auditable execution boundaries.

Slaunt is a work-intelligence and agent-control platform that turns conversations, decisions, incidents, GitHub events, customer notes, and agent activity into shared organizational context. Connected agents such as Claude Code and Codex can query that context before acting, while administrators can scope access, require approvals, set spending limits, monitor runs, route handoffs, pause agents, or stop risky work. The platform records agent actions in an audit trail and states that workspace data is encrypted and not used to train models. Its official structured pricing lists a free Starter tier, a Professional tier at $29 per seat each month, and custom Enterprise pricing.

  • Ingest work signals and agent activity into a live shared context log
  • Provide connected agents with relevant decisions, tasks, incidents, and project updates
  • Apply scoped permissions, approval requirements, tool restrictions, and spending limits
