6 New AI Tools to Explore — September 16, 2026

An editorially reviewed look at six new tools for trusted agent knowledge, visual workspaces, private time tracking, email automation, motion graphics, and dependency upgrades.

By Novera Editorial2026-09-169 min read

This review covers six recently discovered products across Research & Knowledge, Productivity & Automation, Video Generation, and Coding & Development. The selection includes source-grounding infrastructure for agents, an open visual workspace, local AI time tracking, a supervised email agent, editable motion graphics, and automated dependency migrations.

Novera checked each official product page and corrected the automated descriptions, categories, features, and pricing labels. Two false positives were removed from the public directory because they did not fit the site’s AI capability and category requirements. Availability, allowances, and pricing can change, so confirm important details with each provider.

1. Bulkgrid

Give AI agents fresh, searchable context from websites and GitHub repositories.

Bulkgrid indexes selected websites and public or private GitHub repositories so AI agents can retrieve current passages with verifiable references. It handles crawling, content processing, change detection, scheduled refreshes, and search access through MCP, a REST API, SDKs, or a CLI. The free plan searches existing public sources with monthly limits; Pro adds source creation, private sources, larger allowances, and configurable refresh schedules.

  • Index websites and public or private GitHub repositories for agent retrieval
  • Track additions, updates, and removals through scheduled source refreshes
  • Retrieve relevant passages with references through MCP or a REST API
Read the Bulkgrid listing

2. Biom

Turn files written by AI agents into visual pages, dashboards, diagrams, and workflows.

Biom is a visual workspace for material produced by AI agents. An agent writes into a local folder, and Biom presents the results as pages, documents, dashboards, diagrams, tables, boards, forms, or automations that people can inspect and continue editing. The local AGPL-licensed application works with agents that can write files and is free to build and run. Paid collaboration, hosted-agent, sync, web, and mobile plans are listed but were not yet generally available at review time.

  • Turn agent-written files into visual documents, dashboards, diagrams, and forms
  • Work with Claude Code, Codex, OpenClaw, and other agents that can write files
  • Keep pages, data, boards, roadmaps, and automations together in one folder
Read the Biom listing

3. Threshyr

Track desktop activity automatically and classify project time with an offline AI model.

Threshyr is a local-first time tracker for Windows and macOS that records active applications, supported browser domains, duration, and idle periods without manual timers. Rules and an on-device model classify activity by project, while focus views and reports summarize productive time and billable work. The pre-release is free without an account or card; the developer lists a future $58 yearly license, with a discounted first year. Firefox and Linux are not currently supported.

  • Record application and supported-browser activity without starting a timer
  • Classify activity into projects with local rules and an on-device model
  • Review or correct classifications and create reusable tagging rules
Read the Threshyr listing

4. Prmptree

Let a Gmail agent triage messages and propose actions under adjustable human review.

prmptree is a Gmail-focused AI inbox agent that continuously evaluates messages for urgency, context, relationships, and intent. It can draft replies, flag important mail, archive messages, and propose unsubscribe actions before the user opens the inbox. Adjustable trust settings keep actions available for approval, skipping, or correction so the agent can learn preferences. The official site currently offers free Gmail onboarding and does not publish a paid plan.

  • Read incoming Gmail messages and assess urgency, context, and intent
  • Draft replies and flag important messages before the inbox is opened
  • Archive low-value mail and propose unsubscribe actions
Read the Prmptree listing

5. Kario

Generate layered motion graphics with AI, then edit every element on the timeline.

Kario turns a written brief, product URL, logo, images, or product shots into an animated motion-graphics project. Unlike a flattened generated clip, the result keeps its text, shapes, media, keyframes, and timeline editable. Users can request revisions in plain language, adjust layers manually, connect Claude or ChatGPT through MCP, and export landscape or vertical MP4 files. A free plan includes monthly agent credits, with paid plans adding more credits and higher-resolution exports.

  • Create motion graphics from a brief, product URL, logo, or uploaded media
  • Edit generated text, shapes, images, video, audio, keyframes, and timing
  • Request design changes in plain language or adjust individual layers manually
Read the Kario listing

6. apiweiser-cli

Turn breaking dependency releases into tested codemods and reviewable pull requests.

apiweiser-cli monitors dependency releases, uses an LLM to classify potentially breaking updates, and waits for Renovate to confirm that an upgrade is available. It maps TypeScript call sites, asks a coding agent to build and test a deterministic migration codemod, applies the version and lockfile changes, and opens a pull request for review. Codemods are cached and extended across repositories to reduce repeated work. The public repository is released under the MIT License.

  • Watch dependency releases and classify potentially breaking updates with an LLM
  • Confirm available upgrades through Renovate and OSV-backed security information
  • Map TypeScript call sites with the compiler type checker before migration
