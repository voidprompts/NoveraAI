7 New AI Tools to Explore — September 4, 2026

An editorially reviewed look at seven newly discovered tools for image creation, video production, software development, and AI research.

By Novera Editorial2026-09-049 min read

This directory review surfaced seven products with clearly defined uses across Image Generation, Video Generation, Coding & Development, and Research & Knowledge. The selection ranges from free creative and developer utilities to governed cloud infrastructure, with each entry presented as a practical starting point rather than a ranking.

Novera checked each official product page and corrected the initial automated category, pricing, description, and feature data where necessary. Capabilities and prices can change, so confirm important details on the official website before adopting a tool.

1. Videm

Create AI images from text with free guest generations and no platform watermark.

Videm is a browser-based text-to-image generator for visual concepts, product scenes, social creative, and editorial images. Guests can generate up to three images per day without signing in, save the results, and use outputs without a platform watermark. Additional models become available after login.

  • Generate images from natural-language prompts
  • Create up to three guest images per day without signing in
  • Download results without a platform watermark
Read the Videm listing

2. StillMade

Develop consistent AI video projects with guided creation and reusable visual elements.

StillMade is an AI-assisted video workspace built around guided project creation. Its current experience lets creators start image-panel, whiteboard-motion, or blank projects and build a reusable library of characters, locations, and styles to keep visual elements consistent across scenes. The product offers limited free usage and supports bringing your own model API keys.

  • Start guided video projects from several project types
  • Reuse characters, locations, and styles across scenes
  • Organize work into projects and folders
Read the StillMade listing

3. Jern Cloud

Run governed cloud coding sessions under repository-owned policies and hard limits.

Jern Cloud runs coding-agent tasks on isolated machines under a policy pinned for the entire session. It applies hard token and runtime limits, keeps model and repository credentials outside the agent process, records encrypted evidence, and returns work as a pull request for human review. The service includes a 30-day trial, then costs $19 per month per workspace; model usage is billed through the user’s own provider key.

  • Pin repository-owned policies for each session
  • Run attempts on temporary isolated machines
  • Set hard token, runtime, process, and output limits
Read the Jern Cloud listing

4. DrawDB Pro

Design database schemas visually with an AI assistant, collaboration, and DDL export.

DrawDB is a visual database-schema and entity-relationship diagram tool for developers. Its AI schema assistant can draft tables, relationships, and types from a description. The free, open-source editor works without an account and stores diagrams locally, while Pro adds cloud storage, team permissions, versioning, and real-time collaboration.

  • Draft tables, relationships, and types with an AI assistant
  • Import DDL to reverse-engineer an existing schema
  • Export diagrams as DDL, DBML, JSON, or images
Read the DrawDB Pro listing

5. APIMatic Context

Give coding agents typed, API-specific context for more reliable integrations.

APIMatic Context is a registry of installable Context Plugins for AI coding agents. Each plugin combines guidance with typed, language-specific SDK reference code so an agent can handle details such as authentication, retries, rate limits, migrations, and provider changes. The public catalog covers APIs across payments, communications, data, media, and developer tooling.

  • Install API-specific context in a supported coding agent
  • Use typed SDK references alongside written guidance
  • Support new integrations, upgrades, migrations, and provider switches
Read the APIMatic Context listing

6. AIE Talks

Search summaries, timestamps, quotes, and topic packs across AI Engineer talks.

AIE Talks is a searchable written index of more than 1,100 presentations from AI Engineer conferences. It helps visitors find relevant moments through semantic search, concise summaries, timestamps, quotations, speakers, topics, and curated packs. Talk and pack pages are also available as plain Markdown, and the collection is updated as new presentations appear.

  • Search talks by meaning using complete questions or phrases
  • Read summaries, key points, quotations, and timestamps
  • Browse curated packs, conferences, speakers, and topics
Read the AIE Talks listing

7. Supercov

Turn code-coverage gaps into focused testing tasks for AI coding agents.

Supercov is a free, MIT-licensed coverage tool designed to give coding agents actionable testing gaps. It wraps an existing test command, reports uncovered paths, and lets the agent add focused tests and repeat the loop while useful gaps remain. It supports line, branch, and MC/DC coverage across common JavaScript, TypeScript, Rust, and Python test suites.

  • Wrap an existing test command with npx supercov
  • Return uncovered paths that an agent can act on
  • Measure line, branch, and MC/DC coverage
Read the Supercov listing
