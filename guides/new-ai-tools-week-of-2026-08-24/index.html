1. dmx

Add structured, human-gated development loops to AI coding agents.

dmx is an open-source MCP server that adds specifications, plans, validation policies, persistent state, and explicit human approval gates to AI-assisted development workflows.

  • Sequence AI work through spec, plan, build, validate, and release phases
  • Pause at explicit human approval gates
  • Run required and optional validation policies

2. Twing

Coordinate multiple AI coding agents working across the same repository.

Twing is a coordination layer for engineering teams using multiple AI coding agents, designed to expose duplicated work and conflicting changes before they reach review.

  • Show shared agent work across a repository
  • Detect duplicated or conflicting work early
  • Preserve context behind engineering decisions

3. Kith

Ambient clinical documentation and scheduling designed for therapists.

Kith is an AI clinical workspace for therapists that provides ambient transcription, clinically specific SOAP notes, online-session support, scheduling, and reminders.

  • Create clinical SOAP notes from session audio
  • Capture in-person and online session transcripts
  • Manage appointments and recurring sessions
Read the Kith listing

4. H3Max

Generate short videos from text or images with configurable frame controls.

H3Max is a browser-based workspace for creating 5–15 second AI videos from written directions or source images, with prompt expansion and optional first- and end-frame controls.

  • Generate video from text or a source image
  • Create clips between 5 and 15 seconds
  • Choose 480p or 768p output

5. Doodle AI

Turn photos and character prompts into hand-drawn doodle artwork.

Doodle AI creates hand-drawn avatars, sticker packs, portraits, collages, and other illustrated variations from an uploaded photo or a character description.

  • Create a doodle avatar from a photo
  • Choose from multiple illustrated skills and formats
  • Generate sticker, portrait, and collage variations
